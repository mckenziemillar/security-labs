# Security Labs & CTF Writeups

Writeups from hands-on security labs and Capture the Flag challenges I worked
through while studying cybersecurity. Each writeup covers the goal, the tools I
used, how I approached it, the underlying vulnerability, and how a defender
would fix it.

These were course labs and personal practice, not production security work.

## Contents

| Writeup | Topic | Key skills |
|---|---|---|
| [Web Exploitation (picoCTF)](writeups/web-exploitation-picoctf.md) | Cookie tampering & weak credential storage | Browser dev tools, privilege escalation, Base64 |
| [Mapping a Breach to MITRE ATT&CK](writeups/attack-mapping-novatech.md) | Breach analysis with ATT&CK | ATT&CK framework, kill chain, threat analysis |
| [WannaCry Attack Analysis](writeups/wannacry-attack-analysis.md) | Ransomware case study | ATT&CK mapping, incident analysis |
